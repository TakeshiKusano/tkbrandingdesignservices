The Truth ／ はじめに

顧客が最初に抱えているのは、
期待ではなく「失敗への恐れ」。

入るときと出るときで、客の表情も足取りも違う――この「入るときと出るときの違い」こそが、本書全体を貫くテーマである。学習塾の生徒も、ジムの新規会員も、最初に抱えているのは期待より不安である。「今さら通っても手遅れではないか」という諦めに近い感情が、最初の一歩を止めている。

本当の離脱は「来てから」より「来る前」に多く潜んでいる。取り消せない失敗への恐れが、顧客の初期状態を強く支配しているからだ。

8 Fields ／ 全章に共通する発見

業種の違いより、
人間の心理の共通性の方がはるかに大きい。

学習塾、フィットネスジム、ホテル・旅館、クリニック、飲食店、美容室・エステ、小売店舗（アパレル）、BtoB SaaS。業種も規模もまったく異なる8つの現場を舞台に、State Designの7つの道具を実際に当てはめてみせる。各章は「メイン事例」と「サブ事例」の2業種で構成し、章末には「業種を超えた共通パターン」「よくある疑問」「この章の道具を使う三つのコツ」を収録する。

7 Tools ／ 本書の骨格

State Designの7つの道具

七つの章は、それぞれ一つの道具に対応している。どの章から読み始めても構わない。

01

State Journey

状態の旅を描く。初期状態は「期待」より「失敗への恐れ」。

02

State Map

状態の地図を描く。「来る前の離脱」という静かな滞留点に気づく。

03

State Canvas

一枚で設計する。Before状態からAfter状態までを8項目で。

04

State KPI

状態遷移を測る。既存の行動ログだけで健全性を点検する。

05

State UX

状態遷移のためのUI・接客設計。透明性・最短化・感情同期・証拠提示。

06

State Touchpoint

すべての接点を状態遷移で読み直す。つなぎ目の谷に気づく。

07

状態遷移モデル

状態・遷移・確率・介入。他の六つの道具を一つに統合する。
